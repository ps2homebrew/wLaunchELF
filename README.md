
# wLaunchELF

[![CI](https://github.com/ps2homebrew/wLaunchELF/workflows/CI/badge.svg)](https://github.com/ps2homebrew/wLaunchELF/actions?query=workflow%3ACI)

wLaunchELF, formerly known as uLaunchELF, also known as wLE or uLE (abbreviated), is an open-source file manager and executable launcher for the PlayStation 2 console based on the original LaunchELF. It contains many different features, including the following:  

* text editor
* hard drive manager
* FTP support
